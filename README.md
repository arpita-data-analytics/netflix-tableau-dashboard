# 🍿 Netflix Content & Streaming Trends Analysis (Tableau Capstone Project)

## 🚀 Project Overview
This project delivers an interactive Tableau dashboard designed to explore and visualize Netflix's content catalog. By analyzing trends across movie vs. TV show distribution, release years, parental ratings, genres, and geographic production hubs, this dashboard provides clear insights into streaming content strategy and catalog evolution over time.

## 📈 Dashboard Preview
![Netflix Dashboard Preview](dashboard_preview.png)

## 🔑 Key Performance Indicators & Metrics Explored
- **Total Catalog Size:** Breakdown of total titles available on the platform.
- **Content Mix:** Comparative ratio of Movies versus TV Shows.
- **Release Year Trends:** Tracking the growth curve of content additions by year.
- **Rating Distribution:** Analysis of content maturity ratings (e.g., TV-MA, PG-13, TV-14) across genres.
- **Geographic Reach:** Top countries producing content for the platform.

## 🔍 Key Insights Uncovered
1. **Catalog Growth:** Identified peak years for content additions and how streaming production scaled over time.
2. **Format Dominance:** Analyzed the proportional shift between movie releases and multi-season TV shows.
3. **Genre & Rating Clusters:** Highlighted which genres dominate specific content maturity ratings.

## 🛠️ Tools & Skills Demonstrated
- **Tableau Desktop:** Connecting data sources, building calculated fields, and designing clean visual layouts[cite: 4].
- **Data Visualization Best Practices:** Implementing intuitive color themes aligned with platform branding, clear visual hierarchies, and structured dashboard containers.
- **Exploratory Data Analysis (EDA):** Extracting meaningful patterns from raw streaming datasets.
